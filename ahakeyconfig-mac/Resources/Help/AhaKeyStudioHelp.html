AhaKey Studio 도움말 센터

이 로컬 안내서는 현재 클라이언트 화면과 코드 로직에 대응하며, 최초 설정, 권한 문제 해결, AhaType 클라우드 정리, 키보드 설정에 적용됩니다.

최초 실행 과정

AhaKey Studio를 처음 열면 초보자 가이드가 시작됩니다. 가이드 상단에 단계가 표시되며, 하단의 "이전"과 "다음" 버튼으로 진행합니다.

환영 키보드 연결, 백그라운드 음성 키 제어, macOS 네이티브 음성, 입력 체험을 소개합니다.
시스템 권한 블루투스, 입력 모니터링, 손쉬운 사용을 확인합니다. 블루투스는 키보드 검색과 연결에, 입력 모니터링과 손쉬운 사용은 백그라운드에서 실제 음성 키를 제어하는 데 사용됩니다.
음성 권한 마이크, 음성 받아쓰기, Siri, 받아쓰기를 확인합니다. 기본 macOS 네이티브 음성을 사용하려면 이 기능들이 모두 사용 가능해야 합니다.
체험 시작 클라이언트 안에서 동일한 음성 파이프라인으로 한 문장을 말해 보고, 인식과 입력 경로가 정상인지 확인합니다.

켜야 하는 시스템 권한

  1. 블루투스: "개인정보 보호 및 보안 > 블루투스"에서 AhaKey Studio를 허용하고, 시스템 블루투스가 켜져 있는지 확인합니다.
  2. 입력 모니터링: "개인정보 보호 및 보안 > 입력 모니터링"에서 AhaKey Studio를 허용합니다. 백그라운드에서 실제 음성 키를 감지하는 데 사용됩니다.
  3. 손쉬운 사용: "개인정보 보호 및 보안 > 손쉬운 사용"에서 AhaKey Studio를 허용합니다. 음성 키를 macOS 네이티브 받아쓰기나 Fn/Globe 동작으로 변환하는 데 사용됩니다.
  4. 마이크: "개인정보 보호 및 보안 > 마이크"에서 AhaKey Studio를 허용합니다. Apple 네이티브 음성 수집에 사용됩니다.
  5. 음성 받아쓰기: "개인정보 보호 및 보안 > 음성 인식"에서 AhaKey Studio를 허용합니다. 시스템 음성 인식에 사용됩니다.
  6. Siri: "시스템 설정 > Siri 및 Spotlight"에서 Siri를 켭니다.
  7. 받아쓰기: "시스템 설정 > 키보드 > 받아쓰기"에서 받아쓰기를 켭니다.
시스템 설정에서 권한을 이미 켰는데도 클라이언트에 꺼져 있다고 표시되면, AhaKey Studio를 완전히 종료한 뒤 다시 여세요. 입력 모니터링과 손쉬운 사용은 보통 프로세스 단위로 적용되므로, 재시작하면 상태가 시스템 설정과 일치하게 됩니다.

메인 화면 영역

상단 상태 표시줄

상단에는 기기 연결 상태, 배터리, 레버 상태, AhaType 스위치, 키보드 제어 상태가 표시됩니다. "더 보기" 메뉴에서는 기기 재연결, LCD 미리보기 지우기, 기기 정보, 클라우드 계정, 종료 등의 기능을 사용할 수 있습니다.

Keyboard Mode

Mode 탭은 키보드의 각 작동 모드에 대응합니다. Claude Code, Cursor, Codex 세 가지 프리셋은 실제 키 입력 내용과 음성 키 라우팅에 영향을 줍니다.

설정 영역

라이트 바, 화면, 네 개의 키 또는 레버를 클릭하면 해당 설정으로 들어갑니다. 변경 사항은 먼저 로컬에 저장되고, 기기를 연결해 설정 편집 모드로 들어간 뒤 키보드에 동기화됩니다.

오른쪽 검사 패널

"백그라운드 감지 중"은 입력 모니터링과 손쉬운 사용 상태를, "Apple 네이티브 받아쓰기"는 마이크, 음성 받아쓰기, Siri, 받아쓰기 상태를, "AhaType 클라우드 정리"는 클라우드 정리 스위치, 계정 상태, 사용량 정보를 보여줍니다.

AhaType 클라우드 정리

AhaType을 켜면 음성 인식 결과가 먼저 클라우드로 전송되어 정리된 뒤 현재 커서 위치에 입력됩니다. 로그인하지 않았거나 로그인이 만료되었거나 사용량이 부족하면, 클라이언트는 원본 받아쓰기 텍스트를 그대로 입력합니다.

"더 보기 > 클라우드 계정 · AhaType"에서 로그인, 회원가입, 사용량 새로고침, 사용량 교환 또는 구매를 할 수 있습니다.

음성 키 체험

  1. AhaKey Studio를 백그라운드에서 계속 실행합니다.
  2. 권한 검사에서 입력 모니터링, 손쉬운 사용, 마이크, 음성 받아쓰기, Siri, 받아쓰기가 모두 켜져 있는지 확인합니다.
  3. 기기가 현재 Mode 0에 있거나, 대상 Mode에 음성 키가 설정되어 있는지 확인합니다.
  4. 실제 음성 키를 한 번 누르면 녹음이 시작되고, 다시 한 번 누르면 종료되어 현재 커서 위치에 입력됩니다.

하단 상태 표시줄

하단에는 현재 선택된 부품과 모드, 동기화되지 않은 변경 수, 동기화 안내, 최근 동기화 시간이 표시됩니다. 오른쪽 아래의 "초보자 가이드"로 단계별 가이드를 다시 시작할 수 있고, "도움말 센터"는 이 문서를 엽니다.

자주 묻는 질문

마이크를 켰는데 왜 계속 꺼져 있다고 표시되나요?

AhaKey Studio를 완전히 종료한 뒤 다시 여세요. 앱 경로나 서명이 변경되면 macOS가 새 버전을 다른 앱으로 인식할 수 있으므로, 현재 정식 패키지에 다시 권한을 부여해야 합니다.

시스템 설정이 왜 정확한 페이지로 자동 이동하지 않나요?

macOS 버전마다 시스템 설정 URL 지원이 조금씩 다릅니다. 클라이언트는 가장 가까운 권한 페이지를 우선 엽니다. 대상 항목으로 이동하지 못하면 "개인정보 보호 및 보안"에서 해당 권한을 직접 선택하세요.

연결 상태가 왜 Agent 제어 중으로 표시되나요?

평소에는 백그라운드 Agent가 블루투스 연결을 유지합니다. 키 변경, LCD, 동기화 또는 로컬 조명 효과 테스트가 필요할 때는 "설정 편집"을 클릭하면 AhaKey Studio가 블루투스를 임시로 인계받습니다.
